# Blog + Portfolio Information Architecture

## Top-level routes
- `/`
- `/about`
- `/projects`
- `/blog`
- `/blog/[slug]`
- `/404`

## Navigation model
Primary nav:
- Home
- About
- Projects
- Blog

Secondary links:
- GitHub
- Email
- Resume (optional)

## Home
Blocks:
- hero
- featured projects
- recent posts
- quick bio
- CTA to blog/projects

## Blog taxonomy
Suggested categories:
- `42`
- `project`
- `devlog`
- `setup`
- `retrospective`

Suggested metadata per post:
- title
- date
- summary
- category
- tags
- series
- draft

## 42 structure
Each 42 post should support:
- project name
- series group if relevant
- difficulty / constraints (optional)
- lessons learned

Recommended URL style:
- `/blog/42-libft`
- `/blog/42-ft-printf`
- `/blog/42-minishell`
